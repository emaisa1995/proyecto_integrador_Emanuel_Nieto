# Landing Page AutoTodo

## Descripción
Landing Page simple diseñada para promocionar una consecionaria

## Objetivo
Organizar todo el codigo de la landing page y tener un control con las versiones del mismo.

## Estructura del repositorio
* proyecto/: Carpeta que contiene los componentes de código de la landing page.
  * landing_page.html: Archivo de estructura HTML básico.(Archivo Principal Con codigo)
  * styles.css: Archivo complementario para las hojas de estilo del sitio.(Sin codigo)
* README.md: Documentación técnica principal del proyecto.
* ENTREGA.md: Registro del proceso y comandos utilizados.
